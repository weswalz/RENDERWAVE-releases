# RENDERWAVE Releases

Official release builds for RENDERWAVE - Real-time Metal 3 Visual Synthesizer.

## Installation

1. Download the latest `.zip` from [Releases](https://github.com/weswalz/RENDERWAVE-releases/releases)
2. Unzip the file
3. Drag `RENDERWAVE.app` to your Applications folder
4. On first launch, right-click and select "Open" to bypass Gatekeeper

## Requirements

- macOS 15.0+
- Apple Silicon (M1 or later)

## Auto-Updates

RENDERWAVE checks for updates on launch and will notify you when a new version is available.

This is a research preview with frequent updates. Check back often for new features and fixes.
