# RENDERWAVE Releases

Official release builds for RENDERWAVE - Real-time Metal 3 Visual Synthesizer.

## Availability and repository scope

This is a public documentation and distribution repository, not the RenderWave implementation source. At the time of this documentation update, this repository has no published standalone release assets. The installation steps below apply only when a standalone ZIP is available; they are not a current download offer.

ULTIMATEVJ includes 28 built-in RenderWave generators. [See the visual gallery](https://github.com/weswalz/ULTIMATEVJ-releases#renderwave-built-in) and [ULTIMATEVJ installation and preview requirements](https://github.com/weswalz/ULTIMATEVJ-releases#install). ULTIMATEVJ has its own platform requirements and Research Preview limitations; the standalone requirements below do not apply to ULTIMATEVJ.

## Standalone installation reference

1. Download the latest `.zip` from [Releases](https://github.com/weswalz/RENDERWAVE-releases/releases)
2. Unzip the file
3. Drag `RENDERWAVE.app` to your Applications folder
4. Follow the signing and installation guidance supplied with the specific release. Verify the release source before opening the application.

## Requirements

- macOS 15.0+
- Apple Silicon (M1 or later)
